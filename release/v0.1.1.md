# Vasest v0.1.1

Vasest now requires Kinmokusei v0.4.12 or later and Go 1.23 or later.

- Typed error matchers that fill a destination or test the extracted value now take a typed adapter. The README shows how to migrate `expectErrorAs` and the fluent matchers.
- Go paths and messages use `bstring`. Suite and case registration still validates names as UTF-8. Use `null` for omitted Kinmokusei callbacks.
- Assertion diagnostics summarize values when their traversal cannot be bounded. Reports retain failure locations for the compiler's generated calls.

Validation covered generated-Go unit and race tests and 58 integration suites. The Unix socket case requires an environment that permits Unix sockets.
