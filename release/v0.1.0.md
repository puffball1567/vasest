# Vasest v0.1.0

The first public release of Vasest, a testing framework for Kinmokusei applications and libraries.

- Write `.km` tests with typed assertions, fluent matchers, mocks, snapshots and retrying checks. Native numeric widths, nominal types and references remain intact; explicit generic arguments and typed constructors keep type inference optional.
- Organize tests with suites, typed tables, fixtures, setup/cleanup hooks and runtime skips.
- Run tests with filtering, failed-case reruns, file patterns, parallel workers, timeouts, repeat runs, sharding and watch mode.
- Produce text, JSON Lines or JUnit reports, and retain generated-Go coverage, sources and execution artifacts.

Requires Kinmokusei v0.4.3 and Go 1.23 or later. CLI archives are available for Linux and macOS on amd64 and arm64, with SHA-256 checksums. The matching library is available as `github.com/puffball1567/vasest@v0.1.0`.

Assertion locations currently refer to generated Go unless an explicit Kinmokusei location is supplied. Coverage is recorded separately for each generated executable; automatic `.km` mapping and combined project coverage remain future work.

Validation includes generated-Go unit tests, race detection and external Kinmokusei integration tests.
